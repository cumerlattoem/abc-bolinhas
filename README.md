# 📌 Sobre o Projeto

O **Abc Bolinhas** é um projeto colaborativo desenvolvido por **10 estudantes de Sistemas de Informação**. O site apresenta o time em uma **escalação sobre um campo de futebol**: ao clicar em um jogador, o visitante acessa a página pessoal daquele integrante, com seu perfil, habilidades e objetivos.

Cada membro construiu o **próprio espaço**, dentro de um único repositório, usando **HTML, CSS, JavaScript e versionamento com Git e GitHub**.

---
### 🏠 Seção Início
> **Objetivo:** `Apresentar o time` | `Direcionar para o elenco`

| Elemento | Descrição |
| :--- | :--- |
| **Apresentação** | Título "Um time, várias histórias." com texto de boas-vindas. |
| **Chamada** | Botão **Conhecer o elenco** com rolagem direta para a escalação. |
| **Navegação** | Menu fixo no topo: `Início` \| `Elenco` \| `Sobre o projeto`. |

---

### ⚽ Seção Elenco (Escalação)
> **Interações Suportadas:** `Visualizar escalação` | `Selecionar jogador` | `Acessar perfil`

| Elemento | Descrição |
| :--- | :--- |
| **Campo** | Campo de futebol desenhado em CSS: linha central, círculo central e áreas de gol. |
| **Escalação** | Jogadores inseridos dinamicamente via **JavaScript**, sem repetir HTML. |
| **Perfil** | Clique no jogador abre a página individual, mantida na pasta `perfis`. |

---

### 👤 Perfis Individuais
> **Cobertura:** `10 integrantes` | `Página própria por membro`

| Elemento | Descrição |
| :--- | :--- |
| **Autonomia** | Cada integrante desenvolveu e personalizou seu próprio espaço. |
| **Conteúdo** | Trajetória, habilidades e objetivos de cada pessoa do time. |
| **Organização** | Todas as páginas centralizadas na pasta `perfis`, fora da raiz do projeto. |

---

### ℹ️ Seção Sobre o Projeto
> **Objetivo:** `Contextualizar a proposta` | `Registrar o processo`

| Elemento | Descrição |
| :--- | :--- |
| **Proposta** | "Mais que um trabalho em equipe": diferentes perfis reunidos em um único site. |
| **Tecnologias** | HTML, CSS, JavaScript, Git e GitHub. |



# 🗂️ Estrutura do Projeto

```bash
abc-bolinhas/
├── index.html      # Página principal (início, elenco e sobre)
├── style.css       # Estilos globais e desenho do campo
├── scripts/        # JavaScript (renderiza a escalação)
├── perfis/         # Página individual de cada integrante
├── logo/           # Identidade visual do time
└── README.md
```

---

# ▶️ Como Executar

```bash
# 1. Clone o repositório
git clone https://github.com/cumerlattoem/abc-bolinhas.git

# 2. Entre na pasta
cd abc-bolinhas

# 3. Abra o index.html no navegador
# (ou use a extensão Live Server no VS Code)
```

> Projeto 100% front-end: **não exige instalação de dependências**.
