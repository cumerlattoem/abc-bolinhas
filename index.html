O PROJETO

Mais que um trabalho em equipe.

O Abc Bolinhas é um projeto desenvolvido por estudantes de Sistemas de Informação, reunindo diferentes perfis, conhecimentos e interesses em um único site.

Cada integrante desenvolveu seu próprio espaço, utilizando HTML, CSS, JavaScript e ferramentas de versionamento como Git e GitHub.
